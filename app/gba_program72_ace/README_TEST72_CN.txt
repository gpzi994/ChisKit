ChisBurner - smoke.72 GBA NOR 首次实机烧写测试说明

一、测试对象

本包只允许以下目标：

  NOR：S29GL256S，32 MiB
  命令集：AMD
  扇区：128 KiB，共 256 个
  当前写入单元：32 字节

目标身份和 CFI 参数必须与 smoke.71 已验证结果完全一致。任何一项不符，
程序都会在擦除前停止。

本次源文件固定为：

  文件名：逆转裁判.gba
  精确大小：8705280 字节（0x84D500，约 8.302 MiB）
  标题：GYAKUTEN_SAI
  游戏代码：ASBJ
  MD5：07e851b1dc49009ebd00982514ebfe92
  SHA-256：0d0945fff2edd4d4ae627ed003ebb0050937ee689d606ccff89c4ff2c2638571

注意：这个文件并不是严格的 8388608 字节。程序不会截断尾部，必须选择
上述精确大小和哈希的原文件。

二、烧写范围

程序按照识别出的 NOR 总容量执行全片扇区擦除：

  256 个扇区 x 128 KiB = 32 MiB

随后仅将 8705280 字节源 ROM 写入 NOR 起始地址，并对这 8705280 字节
执行最终完整回读 MD5。镜像结尾之后的 NOR 区域保持全擦后的 FF 状态。

本版不使用芯片擦除命令；“全擦”是依次擦除全部 256 个扇区。程序不访问
卡带存档或 RTC。

三、测试前准备

1. 备份当前卡带 ROM、存档和其他重要内容。
2. Pocket 充足电并连接稳定电源，关闭休眠。
3. 测试期间不要拔卡、拔 TF 卡、关闭电源或切换核心。
4. 在电脑上重新核对逆转裁判.gba的大小、MD5和SHA-256。
5. 将压缩包内 SD_ROOT 的全部内容合并复制到 TF 卡根目录。不要只替换
   ELF、OS 或 RBF 中的单个文件。

四、启动与只读预检

在 Pocket 中进入：

  主菜单 -> openFPGA -> ChisBurner -> Play Cartridge

选择逆转裁判.gba。程序首先执行只读预检：

1. 识别目标 S29GL256S 和 CFI 几何；
2. 核对源文件精确大小；
3. 检查 Nintendo Logo、GBA 固定字节和头校验和；
4. 完整读取源文件并计算 SOURCE MD5。

出现人工确认页面前不会执行擦除或写入。请核对屏幕显示：

  SOURCE GYAKUTEN_SAI ASBJ
  SIZE 8705280 B HEADER PASS
  SOURCE MD5 07e851b1dc49009ebd00982514ebfe92
  TARGET AMD ID 227E0001
  FULL ERASE 256 SECTORS

任意内容不同，请按 B 取消并拍照，不要继续解锁。

五、人工解锁

确认所有信息正确后严格按顺序操作：

1. 松开所有按键 0.5 秒；
2. 按住 L+R 2 秒；
3. 松开所有按键 0.5 秒；
4. 按一下 A；
5. 松开所有按键 0.5 秒；
6. 按住 START（+）1 秒。

B 会取消并重新上锁。确认后才开始破坏性操作。

六、执行流程

1. 再次识别目标 NOR；
2. 擦除全部 256 个 128 KiB 扇区；
3. 按 64 KiB 从 TF 读取源文件，底层按 32 字节写入，共 272040 次；
4. 写入过程中重新计算源数据流 MD5；
5. 回读前 8705280 字节并计算 CART MD5；
6. 比较 SOURCE MD5、写入数据流 MD5 和 CART MD5；
7. 无论成功或失败都执行 DISARM 和 SAFE IDLE。

七、成功判据

结果页必须同时显示：

  PROGRAM PASS RC 0
  STAGE COMPLETE
  ERASE 256/256
  PROGRAM 272040/272040
  VERIFY 8705280/8705280
  STOP OFFSET: NONE
  SOURCE MD5 与 CART MD5 完全相同
  DISARM 0 SAFE 0

请拍摄结果第1页和计时第2页。然后完全关机，重新开机并直接运行卡带，
检查逆转裁判能否正常启动。

八、失败处理

出现任何非零 RC、STOP OFFSET、MD5 不一致、红屏或画面冻结时：

1. 拍摄当前完整屏幕；
2. 不要带电拔卡；
3. 不要连续盲目重试；
4. 告知失败阶段、RC 和 STOP OFFSET。

擦除开始后若断电，卡带可能无法启动。恢复时必须冷启动后从头执行完整
烧写，不支持断点续写。
