ChisBurner - smoke.66 GBA NOR 烧写预览版测试说明

一、用途和限制

本包是受限 GBA 卡带烧写程序。它只允许烧写实机识别结果完全符合
以下固定硬件配置的卡带：

  ChisBurner 配置：AGB-E20-30 with S29GL256S10TFI01
  NOR：S29GL256S 兼容、32 MiB
  扇区：128 KiB，共 256 个
  写缓冲：32 字节

它不是通用烧录器，不支持其他 Flash 型号、容量、扇区布局或写缓冲大小。
硬件身份、CFI 命令集和几何参数有一项不符，程序都会在擦除前停止。

smoke.66 修复了 smoke.65 的硬件能力位图重叠。smoke.65 会在真正读取
CFI 前以 TARGET IDENTIFY FAIL RC -10 安全停止；该次失败没有执行擦除或
写入。请勿再用 smoke.65 首测，必须整体安装 smoke.66。

二、测试前必须完成

1. 先用已经通过实机验证的 dump 功能备份卡带 ROM。
2. 先备份存档。程序不会主动访问存档或 RTC，但目标 ROM 与现有存档可能
   不兼容。
3. Pocket 保持充足电量并接入稳定电源；关闭休眠；测试期间不要拔卡带、
   TF 卡或断电。
4. 准备一个恰好 33554432 字节（32 MiB）的 .gba 文件。本次首测建议使用
   已经核对过的中文典藏版绿宝石。
5. 在电脑上先记录源文件 MD5，测试完成后与屏幕上的 SOURCE MD5 对照。

三、安装和启动

把压缩包中 SD_ROOT 目录里的全部内容合并复制到 TF 卡根目录。必须复制
整个包，不能只替换 ELF、OS 或 RBF 中的某一个文件。

在 Pocket 中进入：

  主菜单 -> openFPGA -> ChisBurner -> Play Cartridge

按文件选择提示选中要写入的 32 MiB .gba 文件。这里运行的是烧写核心，
不要从其他核心或菜单中直接启动目标游戏。

四、擦除前的只读预检

程序先进行两类只读检查：

1. 识别目标卡带 NOR，核对厂商、器件、AMD 命令集、32 MiB 容量、
   128 KiB 扇区和 32 字节写缓冲。
2. 完整读取一次源 .gba，检查精确大小、Nintendo 标志、GBA 头校验和，
   并计算 SOURCE MD5。

预检阶段屏幕会明确显示：

  PREFLIGHT ONLY; NO ERASE OR WRITE

任何检查失败时都不会执行擦除或写入。

五、人工解锁顺序

确认屏幕上的源 ROM 信息、MD5 和目标参数都正确后，严格按顺序操作：

1. 松开所有按键 0.5 秒；
2. 按住 L+R 2 秒；
3. 松开所有按键 0.5 秒；
4. 按一下 A；
5. 松开所有按键 0.5 秒；
6. 按住 START（+）1 秒。

选择 B 会取消并重新上锁，不会擦除。每次扇区擦除和每次 32 字节写入都
必须由软件重新提交双密钥授权；一次授权不能重复使用。

六、烧写过程

确认后程序会：

1. 再次识别目标卡带；
2. 擦除 256 个 128 KiB 扇区；
3. 按 64 KiB 从 TF 读取源 ROM，再按 32 字节写入 NOR，共 1048576 次；
4. 写入过程中再次计算流式 MD5，并与预检 SOURCE MD5 比较；
5. 最后完整读取 32 MiB 卡带 ROM，计算 CART MD5，并与 SOURCE MD5 比较。

本版不执行每块写后立即回读，也不执行单独的逐字节 Verify Cartridge；
最后一次完整卡带 MD5 是本版的整体校验。

七、成功判据

结果第 1 页必须同时满足：

  PROGRAM PASS RC 0
  STAGE COMPLETE
  ERASE 256/256
  PROGRAM 1048576/1048576
  VERIFY 33554432/33554432
  STOP OFFSET: NONE
  SOURCE MD5 与 CART MD5 完全相同
  DISARM 0 SAFE 0

请拍摄结果第 1 页和计时第 2 页。成功后正常退出、完全关机，再重新开机
运行卡带，检查游戏启动和实际存档兼容性。

八、失败和断电处理

出现 TARGET IDENTIFY FAIL、SOURCE PREFLIGHT FAIL、PROGRAM FAIL、任意
非零 RC、STOP OFFSET 或 MD5 不一致时：

1. 立即拍摄完整屏幕；
2. 不要在带电状态拔卡；
3. 不要连续盲目重试；
4. 完全关机后再重新开始一次完整烧写。

擦除开始后若断电，卡带会处于已擦除或部分写入状态，暂时不能正常启动。
这不会由程序自动续写；恢复方法是冷启动后从头执行完整烧写。

九、当前状态和后续待办

smoke.66 是未经过实机烧写验证的受控预览版。异步卡带读取、更大的流水
块、单独的 Verify Cartridge 逐字节比较，以及对其他 Flash 型号的支持，
均属于后续版本待办，不在本次测试范围内。
